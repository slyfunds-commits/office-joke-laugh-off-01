## The joke

> The expenses policy is 41 pages. Page 1 says 'use common sense'. Page 39 says 'common sense needs a receipt'.

The policy testifies against itself: page 1's claim, page 39's evidence.
One line, 109 characters, pure ASCII, no trailing newline.

Screened from 308 candidates across 29 fresh office families through the
full judge gate (12/12 checklist, 4 likes, 0 dislikes, P2 + P10); the
expenses-policy contradiction was the best execution of the winning
machinery-testifies device in the set.

`main.py` (pure Python 3.13 standard library, no third-party imports) writes
the entry byte-exact to `/output/entry.txt`.
